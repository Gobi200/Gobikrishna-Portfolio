## 🚀 How to Run Locally

### Option 1: Python Built-in HTTP Server (Recommended)
Open a terminal in this folder and run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.

### Option 2: Direct File Open
Double-click `index.html` in your file explorer to open it in Chrome, Edge, or Firefox.

## 🌐 1-Minute Deployment Options

### Deploy to GitHub Pages (Free)
1. Push this repository to GitHub (`https://github.com/Gobi200/portfolio`).
2. Go to **Repository Settings** -> **Pages**.
3. Under **Build and deployment** -> **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://gobi200.github.io/portfolio/` in seconds!

### Deploy to Netlify / Vercel (Free)
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or connect your GitHub repository to [Vercel](https://vercel.com) with standard static site settings.
